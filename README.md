# Awesome AI Infrastructure

A curated collection of papers, systems, tools, and learning resources for AI Infrastructure research.

> Candidate papers are automatically discovered by [AIInfra-paper-update-tracker](https://github.com/lys122519/AIInfra-paper-update-tracker). This repository contains the reviewed and curated results.

## Scope

- Distributed and parallel training systems
- LLM inference and model serving
- GPU and accelerator resource management
- Collective communication, RDMA, and high-performance networking
- Kubernetes and cloud orchestration for AI workloads
- Memory systems, storage, scheduling, and performance engineering
- Efficient LLM systems, quantization, KV cache, and mixture-of-experts infrastructure

## Update Workflow

1. The tracker scans official DBLP snapshots and produces candidate papers.
2. New candidates are reported through tracker Issues and `AIInfra-Papers.md`.
3. Papers are reviewed for relevance, metadata quality, and category placement.
4. Accepted papers are added here through pull requests.

## Curated Content

The first curated paper collection is being prepared. Contributions through Issues and pull requests are welcome.

## Contributing

Please open an Issue or pull request when suggesting a paper, system, tool, dataset, tutorial, or correction. Include a stable publication link and explain its relevance to AI Infrastructure.
