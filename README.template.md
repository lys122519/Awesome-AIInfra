# Awesome AI Infrastructure

A curated collection of papers, systems, tools, and learning resources for AI Infrastructure research.

> Candidate papers are automatically discovered by [AIInfra-paper-update-tracker](https://github.com/lys122519/AIInfra-paper-update-tracker). This repository contains only reviewed and curated results.

## Scope

- Distributed and parallel training systems
- LLM inference and model serving
- GPU and accelerator resource management
- Collective communication, RDMA, and high-performance networking
- Kubernetes and cloud orchestration for AI workloads
- Memory systems, storage, scheduling, reliability, and performance engineering
- Efficient LLM systems, quantization, KV cache, and mixture-of-experts infrastructure

## Update Workflow

The tracker discovers candidates from official DBLP snapshots. On days 7 and 21, high-confidence matches are collected automatically after passing validation and tests; other candidates remain available for human review through pull requests. See [CONTRIBUTING.md](CONTRIBUTING.md) for the review rules and workflow.
