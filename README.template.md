# Awesome AI Infrastructure

A curated collection of papers, systems, tools, and learning resources for AI Infrastructure research.

> Candidate papers are automatically discovered by [AIInfra-paper-update-tracker](https://github.com/lys122519/AIInfra-paper-update-tracker). This repository contains only reviewed and curated results.

## Scope

- Distributed and parallel training systems
- LLM inference and model serving
- GPU and accelerator resource management
- Collective communication, RDMA, and high-performance networking
- Kubernetes and cloud orchestration for AI workloads
- Memory systems, storage, scheduling, reliability, and performance engineering
- Efficient LLM systems, quantization, KV cache, and mixture-of-experts infrastructure

## Update Workflow

1. The tracker discovers candidate papers from official DBLP snapshots.
2. Candidates are screened for relevance, metadata quality, and category placement.
3. High-confidence matches are collected automatically; ambiguous candidates remain available for human review through pull requests.
4. `scripts/generate_readme.py` validates the data and regenerates this paper list.
5. Human-reviewed rejections are recorded in `data/rejected.yaml` to avoid repeated review; automatic screening never records a rejection.

Automatic synchronization runs on days 4 and 18 at 01:15 UTC, one day after each scheduled tracker update. Every automatic change must pass data validation and the test suite before it is committed.
